# Loan-Approval-Analysis-Dashboard-Power-BI
This project is an interactive Loan Approval Analysis Dashboard developed using Power BI to analyze loan applications, approval trends, applicant demographics, income levels, credit scores, and loan amounts. The dashboard helps identify key factors influencing loan approvals and supports data-driven decision-making.
### Project Objectives
+ Analyze the overall loan approval rate.
+ Evaluate how credit scores impact loan approval decisions.
+ Compare loan amounts across different applicant groups.
+ Identify approval patterns based on employment status, gender, and income group.
+ Provide interactive filters for detailed business analysis.
#### Dashboard Features
### KPI Cards
+  Total Applicants
+  Total Loans Approved
+  Average Annual Income
+  Average Credit Score
+  Average Loan Amount
### Visualizations
+ Loan Approval Distribution
+ Credit Score Impact on Loan Approval
+ Loan Amount vs Annual Income by Gender
+ Loan Approval by Employment Status
+ Existing Loan Distribution by Income Group
+ Annual Income vs Loan Amount Summary
+ Interactive Slicers
+ Credit Group
+ Employment Status
+ Income Group
### Key Insights
+ More than 70% of applicants received loan approval.
+ Applicants with high credit scores have the highest approval rates.
+ Self-employed and employed applicants account for the majority of approved loans.
+ High-income applicants hold the largest share of existing loans.
+ Loan amount distribution varies across gender and income categories.
+ Interactive filters allow users to explore approval trends across multiple applicant segments.
